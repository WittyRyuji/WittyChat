# Governance / 项目治理

## Core commitment / 核心开源承诺

WittyChat's public core is AGPL-3.0-only. Published AGPL grants remain in effect:
later commercial services or agreements do not withdraw rights already granted.
Future public-core contributions remain under AGPL; optional paid modules are
intended to be separately identified and isolated, not hidden restrictions added
to the public license. There is no paid module included in this alpha release.

公开核心永久维持 AGPL 开源方向；自托管不收取软件许可费。
未来可选商业模块、托管服务或支持服务须明确区分，不能收回已发布版本的 AGPL 权利。
商标不在代码许可证授权范围内；不得冒称官方服务。

## Maintainers / 维护者

The repository owner, [WittyRyuji](https://github.com/WittyRyuji), appoints maintainers
and approves releases, architecture and contribution-policy changes.
Technical proposals should be discussed in Issues/PRs; accepted design changes are
recorded in `docs/DECISIONS.md`. Review prioritizes correctness, access control,
durable data, maintainability and self-hostability.

The intended public workflow is feature branches, review, CLA confirmation and
protected `main`. Templates and workflows do not themselves enable branch protection;
repository administrators must configure and enforce it.

## Contributions and rewards / 贡献与回报

Contributors keep copyright and are credited through Git history and release notes.
Bounties may be offered only with explicit scope and agreed payment terms.
There is currently no standing bounty, revenue-sharing promise or guaranteed SLA.
Policy changes should be public and must respect existing license grants.
