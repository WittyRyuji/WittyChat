# WittyChat 架构决策记录

已定稿的决策记录于此。变更需与产品负责人确认后修改。
格式：每条决策标注生效阶段（P0/P1/P2/P3）。

## 0. 定位

- AgenticIM：为 Agent 时代设计的精简企业 IM（小而美）。
- 桌面端为**单一融合界面**（非多个独立界面），邮件在左侧栏（飞书式）。
- 开源核心 AGPL-3.0；付费模块独立隔离；CLA + 公开承诺（核心永久 AGPL）+ 悬赏制回报贡献者。
- 每租户独立实例部署；支持自托管（免费）与云服务；按 region 部署。
- 不做：通用内嵌工作台（网页应用浏览器打开，P2 OIDC SSO）、消息线程（仅引用回复）、访客账号。

## 1. 技术栈

- 服务端：Go。
- 客户端：Wails **v3**（Go 本机层 + TS + React + WebView2，Windows 优先）。
- ACP：客户端 Go 自实现，类型由官方 Schema 生成（不用第三方 SDK 深度绑定）。
- MCP：双向 —— 本机 MCP 服务向 Agent 暴露能力；客户端同时作 MCP 宿主可挂外部 MCP server。
- 数据库：PostgreSQL 17（权威）；客户端 SQLite 缓存。
- 部署：Nginx 单入口；全 Docker；组件可拆机部署；进程间经 PG 协作（LISTEN/NOTIFY 仅作唤醒信号）。
- 不用 Rust 写自研代码；第三方依赖内部用 Rust 可接受。
- 版本基线：Go 最新稳定版、PG 17、Node LTS、React 19、maddy 最新稳定版；所有依赖锁版本（go.mod / pnpm-lock.yaml / 镜像 tag），不用 `latest`；新依赖优先发布满 7 天的版本，入库前过许可证与安全记录。

## 2. 阶段

| 阶段 | 内容 |
|---|---|
| P0 | IM 核心、邮件、管理后台、存储/附件、Agent 接口与数据结构（占位） |
| P1 | 真实 Agent 接入、OnlyOffice、文档/视频预览、表情回应/置顶/收藏/转发/搜索 |
| P2 | OIDC/自建身份中心、浏览器 SSO、移动端+通知、LAN 直传、密码自助找回、Passkey |
| P2–P3 | 跨实例联邦（P2P 短连接、离线队列重试、可选付费 Router、签名+加密） |
| P3 | 超大组织同实例隔离机制 |
| 之后 | Cloud Agent（可能付费）、个人套餐（IM+Agent+存储） |

## 3. 身份与权限

- 单地址：`name@工作区域名` = 登录邮箱 = IM 地址 = 邮箱地址；内部用不可变 ID；改名留别名。
- P0 登录：邮箱 + 密码（Argon2id）；2FA 可选不强制；无 OIDC。
- 开通：Admin 后台创建 → 一次性激活链接（72h）→ 员工网页设初始密码；链接后台可复制，或发往个人邮箱。
- 重置：自助找回 P2；P0 由 Admin 重发一次性链接。
- 离职：交接给工作区 Admin；消息/私聊/助理数据全保留供审计；Admin 查看行为本身记审计。
- 同实例用户无需互加好友；访客不做；非群成员不可见群内容。
- 角色 = 权限组合（系统管理员 / 工作区 Admin / 成员），可拆三权分立以满足等保。
- 会话：设备级，闲置 30 天过期；改密/停用 → 全会话失效并断开。
- 助理权限 = 主人权限 ∩ 助理授权 ∩ 工作区上限。
- 认证目标：ISO 27001 + SOC 2。
- 密码策略默认 NIST：单因子 ≥15 位，开 2FA 可 ≥8 位；禁复杂度规则；禁周期更换；拦常见/泄露密码。等保三级为可选预设。全部策略后台可调（密码/2FA/锁定/超时/日志保留/分权）。
- 审计日志默认保留 180 天；开发按 OWASP ASVS L2。

## 4. 消息与同步

- 会话：私聊（含自己）+ 群（公开可搜可加入 / 私有仅邀请）。无线程。
- 消息 ID：UUIDv7（时间序、离线可生成、联邦不冲突）；会话内 `op_seq` 决定显示序。
- 内容：Markdown，默认上限 2000 字，后台可调，硬顶 5000；UI 显示字数（如 `200/2000`）。
- P0 功能：附件、@、引用回复、编辑（标"已编辑"留版本）、撤回（默认 10 分钟可调）、已读回执（后台可关）、正在输入、在线/离线；@所有人默认群主/管理员。
- 同步模型（两级水印）：
  - 每会话 `op_seq`：消息/编辑/撤回/成员变更统一为 op 流；客户端存每会话水印。
  - 目录比对发现变动会话，只补差额（分页 200/页）；列表先取未读数+预览，正文后台补。
  - 全局低频事件流：好友/设置/助理配置等。
  - 写：HTTPS 幂等（`client_msg_id` 唯一约束）；推：WS 仅提醒，数据以日志为准。
  - 去重：`op_seq ≤ 水印`丢弃（O(1)）；单连接单事件流；重连退避+抖动；密集事件合并推送。
  - 暂态（正在输入/在线）只走内存不落库；已读位置合并只留最新。
  - 全量刷新仅：首次登录、离线超 30 天。
  - 离线外发：本地队列 + client_msg_id，联网重发。
- Agent 输出流（P1）：stream_id + 分片序号，断点续传，按序号拼接去重。

## 5. 存储与对象

- 统一对象表：UUIDv7、归属、大小、SHA-256、MIME、位置（本地/S3）、状态。
- 原始内容 >2MB 分段存储 + 索引表；所有处理流式，不整读内存。
- 上传：≤阈值（默认 5MB 可调）HTTPS 直传→本地盘；>阈值预签名 URL 直传 S3；无 S3 则禁大文件或外链。
- SHA-256 秒传去重；下载经服务端按会话成员鉴权；S3 签短时效下载 URL。
- 预览：P0 仅图片缩略图；文档/视频不预览，显示文件名下载看；附件名入搜索索引。
- 病毒扫描：仅预留后台任务接口（可挂 ClamAV）。
- 配额：工作区级总配额，后台可设，近满告警并阻止上传。
- 清理：孤儿对象（上传未发）7 天清理；撤回消息附件留审计不可见。
- 后台任务：任务表在 PG，worker 消费（缩略图/哈希/冷迁移/邮件解析/GC），独立可重启。
- 冷迁移：按最后访问+上传时间搬 S3，ID 与访问方式不变。
- LAN 直传：P2；P0 留服务端撮合与对象元数据位。
- 备份：部署文档项（对象目录/S3 快照 + PG 备份）。

## 6. 邮件

- 融合界面左侧栏；P0 无 IMAP、无网页邮箱。
- MTA：maddy 首选（可挂 rspamd）；不过关退 Postfix。入站 :25，STARTTLS + MTA-STS。
- 出站：仅直连 MX，不做中继；部署文档必须含 SPF/DKIM/DMARC/PTR。
- 内部邮件：同数据模型，直投不走 SMTP。
- 原文→对象分段；解析结果→PG。
- 搜索：PG 全文（主题+正文+附件名）；附件内容搜索后置。
- 文件夹：收件箱/已发/草稿/垃圾/归档 + 自定义；标签后置。
- 单邮件域/实例；用户别名；多域与邮件列表后置。

## 7. Agent 层

- 客户端运行时（Go）：ACP 自实现 + 适配器注册表 + 进程管理（Job Object 杀树/无黑窗/UTF-8/超时/崩溃恢复）+ 会话管理器（统一流式事件）。
- 两类助理运行时，共用同一内部事件协议与工具面：
  - a) ACP 子进程：Codex、Qwen Code、Claude Code 等完整 Agent；
  - b) 内置 API 运行时：OpenAI 兼容端点直连（DeepSeek、GPT 等纯对话助理）。
- MCP 双向：本机服务暴露 IM/邮件/附件/Zen 工具（按助理权限过滤）；宿主可挂外部 MCP server（助理级配置，工作区允许/禁止清单）。
- 会话操控级别：L1 看 / L2 下指令（默认）/ L3 审批 / L4 全权。
- **助理只接受自己主人的命令**；他人输入一律是不可信数据。
- 代发（消息/邮件）：默认逐条确认；可按助理放宽为自动发 + 审计 + 标"助理代发"。
- 副作用（发消息/改文件/执行命令）必须审批，不静默执行。
- 注入防护：同事消息标记为不可信数据；工具返回值只作数据；架构级隔离。
- 会话数据：transcript 存服务端分段对象 + PG 索引（审计/多端/交接）；实时执行流不上云，按检查点/结束批量同步。
- 审计：hook 层产出审计事件（审批/副作用/会话启止/权限变更）上报服务端；hook 为扩展点。
- P1 适配优先级：Codex → DeepSeek → Qwen。
- 凭证只存本机；助理配置存服务端。
- 模型服务：仅 API 转售；不汇集个人订阅转卖；服务端 Agent 用商业按量 key。

## 8. 部署与其他

- 设置三层：系统（环境变量，后台只读）/ 工作区（管理后台）/ 个人（客户端）；下层不越上层。
- 管理后台单入口按角色分权；首个 Admin 由命令行/首次向导创建。
- 规格：4C/8G 起步（含邮件 + 后续 OnlyOffice）。
- 联邦地址 `name@域名`；用户 ID/消息结构全局可寻址（P0 落地数据结构）。
- Router（付费可选）：内容加密+签名，Router 不可读；内网实例经 Router 收消息（P2–P3 定方案）。
- 安全默认值：全链 TLS；同机容器内网默认不加密可开；密钥加密存储；登录限速+临时锁定。

## 9. 代码规范（已定）

- 语言：注释、文档、commit **中英双语**（commit 用英文标题行 + 可附中文正文）。
- Go：`gofumpt` + `golangci-lint`（聚合 linter，配启用清单）。
- 前端：Biome（lint+format 单一工具）；React 19 + Vite + pnpm。
- 公开 API：第一天起对外兼容 —— Go 代码为唯一事实源，用 huma（或同类）从代码生成 OpenAPI 3.1 spec；外部开发者直接拿 spec。
- 分支/commit：conventional commits 双语；当前小团队轻流程（允许直推 main）；开源公开时切换 main 保护 + feature 分支 + PR + CLA bot。
- 测试：Go 表驱动单测 + testcontainers 真实 PG 集成测试；同步/幂等/权限必测；前端 Vitest + 协议契约测试（op 应用/去重/水印）；P0 后期补 E2E 冒烟；不设覆盖率数字门槛。
- 依赖准入：优先发布满 7 天的版本；入前过许可证与安全记录。
